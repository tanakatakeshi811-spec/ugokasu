# ウゴカス

2Dで描いて、3Dで見る。アニメ工房。

▶ **使う: https://tanakatakeshi811-spec.github.io/ugokasu/**

ブラウザで開いてそのまま使えます。Chrome / Edge ならアドレスバーの「インストール」で **パソコンのアプリ** になります(デスクトップやスタートメニューから起動、ネットにつながっていなくても動きます)。

## できること
- **2D**: ペン(筆圧つき・手ぶれ補正)、消しゴム、塗りつぶし、図形、文字。前後のコマがうすく見える「玉ねぎ表示」でパラパラまんがが描ける
- **2Dで描いて3Dで見る**: 絵のレイヤーに奥行きと厚みをつけて、3Dで回りこんで見られる。撮影カメラを動かすと飛び出す絵本に
- **3D**: 箱・球・星などの立体、ライト。3Dモデル(VRM・FBX・GLB・OBJ・STL)を読みこんで、入っている動きを再生したり、関節をつかんでポーズをつけたり
- **キーフレーム**: 動かすと今のコマに自動でキーが入り、キーとキーの間はなめらかにつながる(動き方は6種類)
- **書き出し**: 動画(MP4 / WebM)・GIF・画像(PNG)・作品ファイル(.json、モデルや画像もいっしょに入る)
- **保存**: 作品はこのブラウザ(アプリ)の中に自動で保存。別の端末へは「作品ファイル」で持っていける
